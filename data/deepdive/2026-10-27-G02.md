**结论：把 Postiz 当成你自己所有小项目共用的「发布底座」，值得，一周内能跑通；拿它做托管排期服务卖钱，不建议。** 理由有三。第一，官方托管版从 29 美元/月起就有 5 个频道、不限帖数，还含 API、MCP 和 CLI。你自己部署也压不出价格优势，反而要自己去过 Meta、TikTok、LinkedIn 的应用审核，还要自己跟进安全补丁：2026 年 4 到 9 月仓库公布了 4 个「严重」级漏洞。第二，这个项目本身就证明了「让 AI 代理来发帖」是真需求：创始人在 Stripe 公开的月收入从 2025 年年中的约 1.7 万到 2.1 万美元，涨到 2026 年 9 月的 18.6 万美元。拉动增长的正是 CLI 和 MCP，钱已经被官方赚走了。第三，对一人公司真正有用的，是用 Claude Code 加 Postiz，把几个 SEO 站、外贸站的内容自动分发到 Pinterest、LinkedIn、X、Bluesky 等平台，每周人工只花一小时左右审稿，换来外部流量。这件事成本低，也能叠加到你已有的项目上。

## 怎么做

先弄清楚它现在的样子：最新版本是 v2.25.3（10 月 24 日发布，修了两个安全漏洞，官方建议立刻升级），38.5k 星，3,479 次提交。从 v2.12 起，排期改由 Temporal 工作流引擎来跑。官方 docker-compose 一共有 9 个服务：Postiz 本体、两套 Postgres、Redis、Elasticsearch、Temporal 和它的管理工具、界面，外加一个调试用的 Sentry Spotlight。官方测试用的机器是 2 核 2 GB 内存。

**两条路线，先选一条**

| | 路线 A：官方托管版 | 路线 B：自己部署 |
|---|---|---|
| 费用 | Standard 29 美元/月（5 频道），Team 39 美元（10 频道），Pro 49 美元（30 频道）；年付打八折 | VPS 约 10 到 12 美元/月（推断，4 GB 内存更稳） |
| 平台审核 | 用官方已经过审的应用，直接授权账号 | 每个平台自己建开发者应用，自己过审 |
| 维护 | 无 | 升级、备份、跟进安全公告 |
| 适合 | **推荐，起步就用这个** | 频道多于 30 个，或者坚持数据放在自己手里 |

**第 1 步：选 2 到 3 个已有项目，定好分发矩阵（半天，0 美元）**
每个项目挑 2 到 3 个平台，不要全铺：
- SEO 内容站（比如某个工具评测站）：Pinterest（图钉带链接，长尾流量）、X、Bluesky；
- 外贸站：LinkedIn 公司页、Facebook 主页；
- 做产品：X、Reddit（只发到允许自我推广的版块）、Threads。
总共控制在 5 个频道以内，正好是 Standard 的额度。

**第 2 步：开托管版试用，接入账号（半天，7 天免费试用）**
注册后接入频道。Instagram 要用专业号；Pinterest 要用企业账号（Company Account）；LinkedIn 公司页要你是页面管理员。试用期内把各平台都发一条测试帖，确认能发出去。

**第 3 步：装 CLI，让 Claude Code 能发帖（1 小时，0 美元）**
- `npm install -g postiz`，然后运行 `postiz auth:login` 授权，凭证存在 `~/.postiz/credentials.json`；
- 或者 `npx skills add gitroomhq/postiz-agent`，把它作为 Skill 装进 Claude Code；
- CLI 能做的事：列出频道、创建和删除帖子、改草稿或排期状态、上传素材、查平台和单帖数据。
- 注意：第三方 MCP 的说明里写着，Postiz 公开 API 默认每小时 30 次请求。一次排一周的帖子够用，但别让代理反复轮询。

**第 4 步：写「内容站 → 社媒」的生成脚本（1 到 2 天，订阅内）**
让 Claude Code 写一个脚本，放在仓库或 VPS 上：
1. 读站点的 sitemap 或 RSS，挑出最近 7 天新增的文章，以及近 30 天流量前 10 的老文章；
2. 每篇按平台写不同版本：Pinterest 写标题、描述和关键词；X 和 Bluesky 写一条要点加链接；LinkedIn 写 150 字左右的行业观点；
3. 配图用文章首图，或者用脚本套模板生成 1000×1500 的竖图（Pinterest 的常用尺寸，推断）；
4. 用 `postiz` CLI 一律**存成草稿**，排进下一周的空档。

Postiz 自带「RSS 自动发帖」，最简单的项目可以直接用它，不写脚本。

**第 5 步：每周审稿（每周约 30 到 60 分钟）**
在 Postiz 日历里过一遍草稿，删掉不合适的，批量改成排期。等跑稳 4 周，再考虑让低风险平台（Bluesky、Pinterest）不经人审直接发。

**第 6 步（可选，第 2 个月起）：换成自部署**
频道超过 30 个，或者想省月费时再换。用官方 `postiz-docker-compose` 部署，加 Caddy 配 HTTPS，并设 `DISABLE_REGISTRATION=true` 关掉公开注册。各平台的开发者应用要逐个申请：Instagram 要业务验证和高级权限审核；LinkedIn 要申请 Advertising API，不然刷新不了令牌；TikTok 没过审核前发的内容只有自己能看到。

**起步成本**

| 项目 | 服务 | 费用 | 依据 |
|---|---|---|---|
| 发布底座 | Postiz Standard（年付 23 美元/月） | 首月 0（试用）到 29 美元 | 官网定价页 |

| **合计第一个月** | | **约 30 到 35 美元，100 美元以内** | |

## 用在哪些场景

1. **SEO 站长给内容站补外部流量**：你手上有 3 到 5 个英文内容站，谷歌更新后自然流量不稳。每篇新文章自动变成 3 到 5 个图钉和 1 条 X 帖。Pinterest 的图钉能被长期搜到，这是最适合「发完不管」的平台。
2. **外贸工厂和 SOHO 的 LinkedIn 公司页「看起来还活着」**：买家查供应商时会看 LinkedIn 和 Facebook 主页，最后一条停在两年前就会扣分。把产品目录、展会照片和已有博客交给 Claude，一个月排 8 到 12 条，每条附一句行业观点，人工每月审一次。
3. **做产品的人公开记录进度（build in public）**：你同时养多个小产品，每个产品在 X、Bluesky、Threads 各开一个号。Claude Code 每周读 git log 和更新日志，写成 3 条进度帖，存成草稿，你周五审一遍。
4. **做数字产品：卖「代理发帖流水线」模板**：把第 4 步的脚本、提示词和 Skill 整理成模板包（比如「Claude Code + Postiz：博客自动分发到 5 个平台」），放在 Gumroad 上卖，买家用自己的 Postiz 账号跑。不需要托管，也不需要售后定制。
5. **自媒体图文账号批量排期**：图文类的知识号（不是视频号）把一周的内容一次排好，评论和数据在 Postiz 里统一看。

## 能实现什么

**场景 1（自用的 SEO 分发）**
- 产出：3 个站，每周各 5 篇，就是每周约 15 篇 × 4 个平台 = 60 条帖子，人工约 1 小时。
- 目标：第 3 个月起，社媒来的推荐流量占到站点总流量的 5% 到 15%（推断，没有找到可靠的公开基准）。按 GA 里 `pinterest.com`、`t.co`、`bsky.app` 的来源算，未达标就砍掉表现最差的平台。
- 依据：Postiz 创始人自己说，Postiz 的发布大部分交给 Postiz 自己做，流量主要来自 X 文章和长期坚持的短内容。这说明「高频、分平台改写」有效，但他的数字（单篇 20.4 万浏览）靠的是个人号的积累，不能直接套。

**场景 4（卖模板）**
- 目标：第一个月 10 到 30 份，每份 19 到 39 美元，就是约 200 到 1,000 美元（推断）。
- 依据：Postiz 有 38.5k 星，Railway 上一个 Postiz 部署模板就有 525 次部署，说明有一批自部署用户，他们需要现成的流水线。不过这个品类没有公开的销量数据，所以只当试水。

**Postiz 本身的成绩，可以当作这条赛道的天花板参照**
- 2024 年 9 月 1 日发布；2025 年年中月收入约 1.7 万到 2.1 万美元；发布 CLI 和 MCP 约两个月后涨到约 7 万美元；2026 年 4 月 2 日前后年化收入过 100 万美元；7 月 12 日在 TrustMRR 上是 167,620 美元/月，付费订阅 4,971 个；9 月创始人公开的 Stripe 数字是 186,713 美元/月。
- 读法：一个创始人加开源，两年做到这个规模，说明「卖给代理用的发布接口」在 2026 年是增长最快的一块。但它已经占住了位置，你不应该正面去做同样的东西。

## 自动化架构

| 环节 | 谁来做 | 说明 |
|---|---|---|
| 抓新文章和高流量老文章 | VPS 定时任务或 GitHub Actions，每周日跑 | 读 sitemap、RSS，调 GA 或 Search Console 接口 |
| 按平台改写、生成标签 | Claude Code（无人值守模式） | 提示词里分别写好每个平台的风格和字数，存进仓库 |
| 配图 | Python 脚本套模板 | 不用 AI 生成图片，免得被平台判成低质 AI 内容 |
| 存草稿、排期 | `postiz` CLI | 默认只存草稿；每次最多 50 条，避免撞上每小时 30 次请求的限制 |
| 每周数据汇总 | 脚本调 `postiz` 的 analytics 命令，再加 GA 来源数据 | 生成一页报表发到飞书 |
| **审稿和批量发布** | **你** | 每周 30 到 60 分钟 |
| **平台警告和封号处理** | **你** | 出现时处理，平均每月不到 1 小时（推断） |
| 外贸客户的资料收集和月度审核 | 你 | 每家每月约 30 分钟，最多 5 家 |

稳定后每周：只做自用的约 1 小时；加上 3 家外贸客户约 2 到 2.5 小时，不超过 3 小时。

## 未来预测

- **6 个月（到 2027 年 4 月）**：「代理调用发布接口」会成为排期工具的标配，Buffer、Mixpost 已经提供 API 或 MCP（Mixpost Pro 的买断价 299 美元里就含 MCP）。Postiz 会继续靠开源和代理的口碑增长，但增速会放缓，因为 2026 年上半年那一波和 OpenClaw 等代理框架的走红有关，这种红利不会持续。**把握中等**。
- **12 个月**：平台对「AI 批量发帖」的识别和限流会更严。X 的 API 已经改成按量计费，2026 年 4 月 20 日起，普通帖从 0.01 美元涨到 0.015 美元，带链接的帖子从 0.01 美元涨到 0.20 美元，涨了 20 倍，明显是在压低链接帖。Meta、TikTok 的审核门槛也只会更高。这会让托管版更值钱（审核由官方去过），自部署更难。**这一条把握较大**，依据是 X 的价格已经变了。
- **24 个月**：排期工具本身会越来越便宜，只剩「哪个平台还给流量」的问题。社媒推荐流量会不会被 AI 搜索截走，**看不清**。所以这套东西的价值在于低成本、可以随时关，不要往里面投重资产。
- **Postiz 项目本身的风险**：从 Apache 2.0 改成了 AGPL-3.0，所以以后改许可证或者收紧开源版功能都有可能。目前 README 写着不按功能分版本，也不限制许可证，但这只是现在的承诺。

## 风险与对策

1. **平台政策：AI 批量内容和自动化被限流或封号**。X 对自动化和带链接帖收费高、限流严；Pinterest、LinkedIn 对重复内容和刷量很敏感。**对策**：每个账号每天不超过 2 到 3 条；每个平台单独改写，不同号不发同一段话；用文章原图，不用 AI 生成图；重要账号（外贸客户的公司页）一律人工审后再发。
2. **平台审核卡住（自部署时）**：Meta 要业务验证和高级权限审核，LinkedIn 要申请 Advertising API，TikTok 没过审核的帖子只有自己能看到。**对策**：起步用托管版，直接绕过审核；真要自部署，先只接 X、Bluesky、Mastodon、Pinterest 这几个门槛低的平台。
3. **安全漏洞**：2026 年 4 到 9 月公布了「未认证就能读任意文件，进而接管实例」「未认证就能还原随机数状态，泄露 OAuth 令牌」等多个严重漏洞，10 月 24 日又修了两个。自部署一旦被打穿，你所有社媒账号的令牌都会泄露。**对策**：自部署只放在 Cloudflare Access 或 Tailscale 后面，不对公网开放；在 GitHub 上关注这个仓库的 Releases，有安全版本就当天升级。
4. **AGPL 许可**：如果你改了 Postiz 代码再托管给别人用，必须向用户公开修改后的源码。**对策**：不改源码，只通过 API 和 CLI 调用；卖的是自己写的脚本和模板，不卖 Postiz 本身。
5. **API 请求限制和依赖单一供应商**：公开 API 默认每小时 30 次请求，Postiz 涨价或者改条款，你的流水线就受影响。**对策**：脚本里把发布这一层抽象出来，以后能换成 Buffer API（免费版每月 3,000 次请求）或 Upload-Post 这类发布接口。
6. **白忙：社媒流量不转化**。**对策**：第 4 周看 GA，社媒来源不到总流量 3% 的平台直接停掉。
