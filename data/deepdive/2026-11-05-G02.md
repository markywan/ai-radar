**结论：Horizon 本身值得装来自用，但「拿它做行业情报周报、按月卖给跨境卖家」现在不值得做，按关 1 归档。** 原因：我没找到任何一个「AI 自动汇编的行业简报」有核实过的、像样的订阅收入。最接近的 [Digest](https://trustmrr.com/startup/digest) 做了 4 年（2022-10 起），TrustMRR 上只有 65 个订阅、MRR 489 美元；同样做付费简报的 [The MRR Brief](https://trustmrr.com/startup/the-mrr-brief) 标价 199 美元/月，订阅数是 0；面向美国进口商的 [Tariff Intel Brief](https://tariff-intel-brief.pages.dev/) 标价 500 美元/月，还在收候补名单，没有任何买家证据。beehiiv 官方报告里付费转化的中位数只有 0.62%（[来源](https://www.beehiiv.com/blog/the-state-of-paid-newsletters-2026.md)），按商业类中位价 15 美元/月算，1000 个免费订阅大约只换来 90 美元/月，而他手上没有现成的跨境卖家英文邮件名单。Horizon 真正的用处是**给他自己的 SEO 站、图文号和找机会当素材引擎**。如果一定要试卖钱，只按下面的「先预售 3 笔」方案做，30 天内凑不到就停。

## 怎么做

只按「低成本验证版」写：选一个窄方向，先卖再做。示例方向：**「美国进口关税和平台政策周报」，给年销 50 万美元以下、卖到美国的中小卖家**（关税变化快、他们有真实损失，比泛泛的「行业新闻」好卖）。

1. **第 1 天：装 Horizon 跑通（2 小时，0 美元）**。MIT 许可，`uv` 或 Docker 装到现有 VPS，或者用仓库自带的 GitHub Actions 模板定时跑。`data/config.json` 里配信息源：Google News、GDELT、RSS（CBP、USTR、Federal Register、Amazon Seller News、Marketplace Pulse、EcommerceBytes）。Reddit 先不配：Reddit 2026-11-13 停 RSS，Horizon 的 Reddit RSS 回退也有未修的 bug（[#186](https://github.com/Thysrael/Horizon/issues/186)）。X 要走 Apify，额外花钱，先不开。
2. **第 1–2 天：写一个专用 profile（3 小时）**。Horizon 用 profile 定打分标准和输出格式。打分只奖励「影响进口成本或上架资格的变化」，输出固定三块：本周变了什么、对谁有影响（按 HS 大类）、下周要盯的截止日期。阈值先设 7.0（官方示例值），一期控制在 8–12 条。
3. **第 2 天：选模型（30 分钟）**。DeepSeek 或 Gemini Flash 这类便宜模型做打分和摘要，每天几百条素材，月成本估计 5–15 美元（推断，按条数和单价估）。注意：用 Claude 4.7 以后的模型，Horizon 目前会报 400 错（[#188](https://github.com/Thysrael/Horizon/issues/188)），先别用 Anthropic 接口，或者自己补一行去掉 temperature。
4. **第 3 天：建落地页和收款（3 小时，约 10 美元）**。买域名，用 Horizon 自带的 GitHub Pages 发布做公开样刊（放最近 3 期，其余付费），首页放 Creem 付款链接。
5. **第 3–7 天：先预售再送达**。在卖家聚集的地方发样刊，拿到 3 笔付款之前不建邮件系统；付了钱的先手动发 PDF 或私密页链接。
6. **过了预售之后才接邮件**：beehiiv 免费档放免费版名单；付费版用 Creem 的订阅加一个私密页面（或 Horizon 的 Webhook 推到付费用户的 Slack/Discord）。不建议用 Horizon 自带的 SMTP 群发，作者自己说过邮件订阅「容易被封号」才没开（[#8](https://github.com/Thysrael/Horizon/issues/8)）。

| 项目 | 用什么 | 费用 |
|---|---|---|
| 运行 | 现有 VPS 或 GitHub Actions | 0 美元 |
| 大模型接口 | DeepSeek / Gemini Flash | 5–15 美元/月（推断） |
| 域名 | 任意注册商 | 约 10 美元/年 |
| 落地页、样刊 | GitHub Pages（Horizon 自带） | 0 美元 |
| 免费名单 | beehiiv 免费档 | 0 美元 |

| 冷启动小额投放（可选） | Reddit/X 帖子推广 | 0–50 美元 |
| **合计首月** | | **约 25–75 美元** |

## 用在哪些场景

1. **他自己的 SEO 与 GEO 站**：Horizon 每天按某个外贸品类筛新闻，挑出高分条目当文章选题，比手动刷 RSS 省时间。这是最确定有用的场景。
2. **他的图文自媒体**：中英双语简报直接当选题池，英文版改写成 X 长帖或 LinkedIn 帖，中文版改成公众号、小红书图文。
3. **找机会**：盯 Show HN、GitHub、Google News 里某个行业的新品和需求，给 ai-radar 这类日报当第二路素材。
4. **（待验证）卖到美国的中小卖家**：关税、清关、小包免税、平台政策突然变，他们要在采购和定价之前知道。现在多是看 Flexport 免费周报、卖家群、雨果网这类免费来源。
5. **（待验证）小型货代、报关行**：想给自己客户转发「本周关税变化」，又没人写。可以卖成白标版（每周给他们一份可以改抬头的稿子），不过这接近定制，他要谨慎接。

## 能实现什么

- **自用产出（确定）**：每天一份 8–12 条、打过分的行业简报，进他自己的选题池，每周省 2–3 小时人工筛选（推断）。
- **付费周报（不确定，按 beehiiv 中位数推）**：免费名单 300 人 × 0.62% ≈ 2 个付费用户；按 15 美元/月算约 30 美元/月。要到 500 美元 MRR，得有约 33 个付费用户，按中位转化率要约 5000 个免费订阅，90 天里没有现成渠道很难做到。转化率前 10% 的商业、财经类能到 5%–20%，所以**窄而且直接关系到钱的选题**（关税、合规截止日期）是唯一可能跑赢中位数的路。
- **可衡量的目标**：30 天 3 笔预售、免费名单 200 人；60 天 MRR 100 美元；90 天 MRR 500 美元。

## 客户画像

- **谁付钱**：年销 10 万–50 万美元、卖到美国的 Amazon、Shopify、TikTok Shop 卖家，自己管采购和定价，没有专职合规人员。这类卖家有多少、有多依赖小包免税，这次没找到能打开核实的数字（推断这是人数最多的一层）。
- **在哪找**：r/AmazonSeller、r/FulfillmentByAmazon、r/ecommerce（发帖要守版规，不能硬广）；X 上的跨境卖家圈；Facebook 卖家群；Marketplace Pulse、EcommerceBytes 文章下的评论区。
- **现在怎么解决**：看免费来源，比如 Flexport 每周货运更新、NCBFAA 每周提醒（这两个只在搜索结果里看到，没打开）、[Buttondown 上的 Tariff Tracker](https://buttondown.com/tariff-tracker)（每周一出，没公开价格）；或者问货代。
- **愿意付多少**：没看到有人公开付费的数字。beehiiv 商业类中位价是 15 美元/月，财经类 20 美元/月；Tariff Intel Brief 标 500 美元/月但没有卖出去的证据。建议定在 15–29 美元/月（推断）。
- **Horizon issue 区给的切入点**：开着的 issue 只有 3 个，用户要的是 Bug 修复（Claude 新模型报错、Reddit 评论抓不到）和 Telegram 公开群组读取（[#191](https://github.com/Thysrael/Horizon/issues/191)）。关掉的 issue 里最热的需求是「能不能直接订阅你每天生成的日报」（[#8](https://github.com/Thysrael/Horizon/issues/8)，14 条评论）、「能不能推送到微信公众号」（#63）、「能不能加小众网站，比如购物网站」（#44）、配 DeepSeek 和中转 API（#39、#41、#42，最多 16 条评论）。也就是说，**用户想要现成的成品简报和更简单的配置，没人提出要付费托管版**。卖「Horizon 托管版」也没有需求证据。

## 获客与定价

**第一批 10 个客户：**
1. 他自己的外贸、跨境人脉，私信发 3 期样刊，问「这个值 15 美元一个月吗」，目标 3 笔预售。
2. 在 r/AmazonSeller 等版块，每周发一条有干货的关税变化总结（不放链接，或按版规只在个人主页放），评论区有人问再给链接。
3. 在 X 上把每周最重要的 3 条关税变化做成串推，末尾放免费订阅链接。
4. 找 2–3 个小货代，免费给他们的客户群转发简报，换个署名链接。
5. 在 Show HN 发「我用开源 Horizon 做了个关税周报」，开发者圈不是目标客户，但能带来反向链接和少量卖家。

**定价：**
- 免费版：每周 3 条最重要的变化。
- 付费版：19 美元/月或 190 美元/年，每周完整版加 HS 大类筛选加截止日期日历。
- 预售价：前 10 个用户 9 美元/月终身锁价，用来测愿不愿意掏钱。
- 不做：一对一咨询、按客户定制品类（他不做大量定制）。

## 自动化架构

- **VPS 或 GitHub Actions 定时任务**：Horizon 每天抓取、去重、打分、出简报；每周日把 7 天高分条目合并成周报草稿。
- **Claude Code / Codex**：维护 Horizon 配置和 profile；周报草稿由便宜模型出，Claude 只做最后一遍的事实核对提示（标出没有原文链接的数字）。
- **开源项目**：Horizon（MIT），beehiiv 管免费名单，Creem 管订阅。
- **仍要人做**：每周花 30–45 分钟看一遍周报，删掉错的；回复读者邮件；每月调一次信息源。
- **稳定后每周约 1.5 小时**（推断），在 3 小时的上限以内。

## 未来预测

- **6 个月**：Horizon 7 天涨了 1448 星、总星数 12.8k，还会热一阵；同类「自托管 AI 新闻雷达」会更多，「用开源工具自动出简报」这件事越来越不稀奇，单靠「AI 汇编」卖不出溢价。美国关税政策 2025–2026 年变动频繁（具体税率这次没逐条核实，写周报时以 CBP 和 Federal Register 原文为准），只要政策还在变，卖家就有关注的理由。
- **12 个月**：Flexport、货代、ERP 厂商的免费内容会继续把「关税新闻」免费化，付费只剩「按我的品类算好影响」这一层。这一层要准确，一出错就退订，靠 AI 全自动风险大。
- **24 个月**：不确定。如果关税政策稳定下来，这类周报的需求会掉一大截；AI 搜索（Perplexity、ChatGPT 搜索）也可能直接替代「每周看一份简报」的习惯。
- 判断依据有限：上面没有一个同类产品给出可核实的增长曲线，这一段多是推断。

## 风险与对策

1. **没人付钱**（最大的风险，证据已经指向这一点）。对策：先预售，30 天不到 3 笔就停，Horizon 留作自用。
2. **AI 摘要写错关税数字**：卖家按错的数字定价会造成真实损失，也会引来退款。对策：每条必须带原文链接；数字只从原文抄，模型只负责归类；首页写明「仅供参考，不是报关意见」。
3. **信息源政策变化**：Reddit 2026-11-13 停 RSS；X 抓取要付费给 Apify，且违反 X 条款的风险由他承担；Google News 抓取不稳定。对策：主要用官方 RSS（CBP、Federal Register、USTR）和 GDELT，社交平台只当补充。
4. **收款平台审核**：Creem 把「生成式 AI 产品」和「新闻通讯广告」列为限售，要做加强审核（[来源](https://docs.creem.io/merchant-of-record/account-reviews/account-reviews)）。对策：申请时写成「付费行业研究周报（数字订阅内容）」，事先问客服确认；不卖广告位。
5. **版权**：简报里大段转载新闻原文会侵权。对策：每条只写 2–3 句自己的话的摘要，再附原文链接。

## 第一周行动清单

- [ ] 第 1 天：VPS 上用 Docker 装 Horizon，配 DeepSeek 接口，用默认 profile 跑出第一份简报
- [ ] 第 1 天：按「关税和平台政策」写信息源清单（CBP、USTR、Federal Register、Amazon Seller News 等 RSS，加 Google News 关键词）
- [ ] 第 2 天：写专用 profile 和打分标准，连跑两天，人工看命中率，不相关的超过 30% 就改标准
- [ ] 第 3 天：买域名，GitHub Pages 发样刊页；注册 Creem，先问客服订阅内容能不能过审
- [ ] 第 4 天：做第一份完整周报，人工逐条核对数字和链接
- [ ] 第 5 天：私信 15 个外贸、跨境熟人发样刊，问愿不愿意 9 美元/月预订
- [ ] 第 6 天：在 r/AmazonSeller 和 X 各发一条关税变化总结（守版规）
- [ ] 第 7 天：数结果，有没有收到第一笔钱、有多少人回复；同时把 Horizon 接进他自己的 SEO 选题流程（这一步不管成不成都做）

## 怎么收钱

- **能收到**：卖法是按月或按年订阅，属于数字内容，两家代收平台都支持订阅。
  - [Creem](https://www.creem.io/pricing)：3.9% + 0.40 美元/笔，没有月费，自带订阅管理。19 美元一笔到手约 17.86 美元。
  - [Dodo Payments](https://dodopayments.com/pricing)：美国卡 4% + 0.40 美元，非美国卡加 1.5%，**订阅再加 0.5%**；定价页写普通提现免费，FAQ 又写 1000 美元以下提现收 5 美元，两处矛盾，用之前问清楚。
- **禁售、限售清单**：Creem 允许的类别写的是软件、SaaS、电子书、PDF 等数字商品，没有直接点名「新闻通讯订阅」；「新闻通讯广告」和「生成式 AI 产品」在限售名单里，要加强审核（[清单](https://docs.creem.io/merchant-of-record/account-reviews/account-reviews)）。卖周报订阅本身应该能过，但不能卖广告位，上线前先找客服确认。
- 回款走万里汇，提现人民币 0.7% 封顶。Stripe 不收大陆商户，Lemon Squeezy 新项目别用。
- 如果以后想靠广告赚钱，Creem 那条路走不通（新闻通讯广告是限售），要另找办法，到时再查。

## 合规红线

- **发信**：给 Gmail 发信要配 SPF 或 DKIM，配 PTR 记录，走 TLS，投诉率低于 0.3%（Google 建议低于 0.1%）；一天发给 Gmail 超过 5000 封要三项全配（SPF、DKIM、DMARC），还要支持一键退订（[Google 规则](https://support.google.com/a/answer/81126)）。能做：用 beehiiv 这类平台发给自己报名的人。不能做：把从网上搜来的卖家邮箱导进去群发。
- **美国 CAN-SPAM**：写真实发件人、实体地址，10 个工作日内处理退订。实体地址可以用虚拟信箱地址。
- **加拿大 CASL、欧盟 GDPR**：订阅表单要用户自己勾选同意，留下同意记录；不给没有报名的欧盟、加拿大邮箱发信，德国、奥地利先不推广。
- **抓数据**：Horizon 抓的是 RSS、公开 API、Google News。能做：用官方 RSS 和 API。不能做：抓禁止抓取的付费新闻网站全文。怎么才行：新加信息源前先看 robots.txt 和网站条款，只存标题、链接和自己写的摘要。Reddit 商业用途要遵守它的数据 API 条款（这次没能打开条款原文，接 Reddit 之前要自己去读）。
- **X**：Horizon 通过 Apify 抓 X，违反 X 条款的风险由他承担，付费版先不用 X 当信息源。
- **开源许可证**：Horizon 是 MIT，可以改、可以拿来做付费服务，保留原版权声明就行。
- **内容责任**：关税内容不能写成「报关建议」，页脚写免责声明，不保证准确。

## 90 天过关数字

这个项目按默认标准，**关 1 已经不过**：没找到 AI 汇编简报有人在稳定付费，他也没有现成的跨境卖家英文渠道。所以默认是**归档付费版，只把 Horizon 留作自用素材引擎**。如果仍想试，关卡改严，用预售代替关 1：

| 关 | 日期 | 数字 | 否则 |
|---|---|---|---|
| 关 1（改） | 2026-11-12 | 7 天内收到 3 笔预售（任何价位），或 15 个私信对象里有 5 个明确说要 | 归档付费版，Horizon 只自用 |
| 关 2 | 2026-11-12 | Creem 过审能收款 | 只剩免费版，当 SEO、自媒体的引流素材 |
| 关 3 | 2026-12-05 | 至少 1 笔陌生人付款；免费名单到付费的转化 3% 以上，或私信、发帖回复率 5% 以上 | 停付费版 |
| 关 4 | 2027-01-04 | 月收入 100 美元以上且在涨，退款加拒付低于 2% | 冻结，不再加信息源 |
| 关 5 | 2027-02-03 | MRR 500 美元以上，或每小时回报 50 美元以上 | 把名单和配置打包卖掉，或者停更 |

调整原因：关 1 从「已有人付费」改成「自己 7 天预售 3 笔」，因为同类产品没有可核实的收入证据，只能直接拿钱测。
