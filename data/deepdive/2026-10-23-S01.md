**值得装，但它本身不赚钱。** 这 52 个技能是免费的营销方法清单（MIT 许可，skills.sh 上整套 580 万次安装），谁都能用，所以护城河不在技能，在你喂给它的数据和行业经验。最适合你的用法是拿 `programmatic-seo` + `free-tools` + `seo-audit` 三个技能，做一个**面向美国进口商的「某类产品从中国进口：关税 + 到岸成本」工具站**：用公开的美国关税表（HTS）加你自己的外贸经验做页面，靠卖询盘线索和广告变现。起步约 75 美元。SEO 起量慢，6 个月内基本没收入，这一点要先接受。

## 怎么做

先定一个你做过外贸的品类（比如户外家具、厨房用品），只做这一类，不铺全品类。

| 步骤 | 用什么 | 花费 | 时间 |
|---|---|---|---|
| 1. 装技能、写产品背景 | `npx skills add coreyhaines31/marketingskills --skill programmatic-seo free-tools seo-audit site-architecture schema`；让 Claude 用 `product-marketing` 技能生成 `.agents/product-marketing.md`（其他技能会先读它） | 0 | 半天 |
| 2. 验证需求 | DataForSEO 关键词接口查「import [产品] from china」「[产品] tariff」「[产品] hts code」这类词的量和分布，`programmatic-seo` 第 3 步要的就是这个 | 50 美元起充，余额不过期 | 1 天 |
| 3. 拉数据 | USITC 官方 HTS 导出（JSON/CSV，可走 REST API），只取你那一章的税号；再写一张你自己的表：常见 MOQ、外箱尺寸、交期、需要的认证（UL/FCC/CPSIA 等） | 0 | 1–2 天 |
| 4. 做免费工具 | 到岸成本计算器：箱规→CBM→整柜/拼柜运费估算＋关税＝每件到岸价。按 `free-tools` 的打分表先评一遍再做 | 0 | 2 天（Claude Code 写） |
| 5. 出页面模板 | Astro 静态站，按 `programmatic-seo` 的模板结构：关键词标题、独有导语、数据区块、相关页内链、行动按钮（「要这类产品的工厂报价」表单） | 0 | 2 天 |
| 6. 上线 | Cloudflare Pages 托管，域名一个 | 域名约 10–15 美元（推断） | 半天 |
| 7. 每日更新 | GitHub Actions 每天拉一次 HTS，和昨天的快照比对，有变化就重建相关页并记进「关税变化记录」页 | 0 | 半天 |
| 8. 体检、提交收录 | `seo-audit`、`schema` 技能过一遍；Search Console 提交分类型站点地图 | 0 | 半天 |

**起步成本合计约 65–75 美元**（DataForSEO 50 + 域名 10–15 + 余量），Claude 用现有订阅。

两个要点：

- **只出「有数据差异」的页面。** 技能里写得很直白：「宁要 100 个好页面，不要 1 万个薄页面」，最常见的错误是「只换城市名、内容一样」。所以先出 50–100 个税号页，每页都要有你那张经验表里的独有数据，没有的就 noindex。
- **HTS 官方 API 只给当前版本，不给历史。** 你每天存快照，攒下来的「哪个税号哪天变过」就是别人没有的数据。按技能里的分法，自有数据最难被抄，纯公开数据最容易被抄。

## 用在哪些场景

1. **美国亚马逊、独立站卖家选品时**：想知道一个产品从中国拉过来每件到岸多少钱，搜「[产品] import duty from china」，进计算器页。
2. **关税调整当周的小批发商**：税率一变就搜，你的「关税变化记录」页和邮件提醒正好接住这种需求。
3. **第一次找中国工厂的美国小品牌**：看完到岸成本，顺手填「要报价」表单，这就是你能卖的线索。
4. **（顺带）你自己所有的小项目**：每个项目一份 `product-marketing.md`，上线时用 `directory-submissions` 列提交清单、用 `copywriting` 写落地页、用 `competitors` 写对比页。这套技能就是一个不收钱的营销部，省下的是时间，不直接变成收入。
5. **（顺带）外贸开发信**：`cold-email` 的规矩可以直接照着用，比如主题 2–4 个小写词、3–5 封跟进、退订行和邮寄地址必带、关掉打开和点击追踪、新域名先预热 3–4 周。

## 能实现什么

以下数字除注明出处外都是**推断**：

| 时间 | 页面 | 月访问 | 收入 |
|---|---|---|---|
| 第 3 个月 | 100 个税号页 + 1 个计算器 | 几百 | 0 |
| 第 6 个月 | 300 页 | 1,000–3,000 | 线索 0–300 美元 |
| 第 12 个月 | 500 页 + 邮件提醒 | 5,000–10,000 | 300–1,500 美元/月 |

依据：
- Mediavine Journey 的门槛 2026 年 1 月降到每月 1,000 次会话（多个来源一致，但要求以一线国家流量为主），达到这个量就能接广告。
- 中国代采代理一般收订单金额的 5%–10%（supplyia），也就是说一单 2 万美元的订单能给代理带来 1,000–2,000 美元，所以他们出得起每条线索几十美元。这个价格是推断，要你自己去谈。
- 风险因素：Seer Interactive 统计了 53 个品牌、547 万个搜索词，出 AI 概览时自然点击率 2025 年 12 月最低到 1.31%，2026 年 2 月回到 2.36%，同期不出 AI 概览的是 3.82%。纯问答类内容会被 AI 概览截走，**计算器和随时变的数据表被截走得少**（推断），这也是选工具站的原因。

## 获客与定价

**前 10 个付钱的客户是线索买方，不是网站访客。**

1. 第 1 周就去联系你认识的 3 家代采或验货公司，先说好免费试送 5 条线索，满意再按条收费。这是熟人生意，不用冷开发。
2. 第 2–3 个月网站有询盘后，用 `cold-email` 技能写一套 4 封的序列，发给 Google 搜出来的 20 家同品类代理。附上真实的询盘样例（隐去联系方式）。发送量很小，不用买 Instantly（Growth 套餐每月 47 美元）。
3. 访客侧用 `directory-submissions` 把计算器提交到工具类目录和 Product Hunt。技能要求每次提交都由人确认，不要批量自动提交，也别买 60–200 美元的代提交服务。

**定价：**
- 线索：每条 30 美元起（推断），独家线索价格翻倍；也可以谈成交后抽订单金额的 1%。
- 关税提醒邮件：前 6 个月免费积累名单，之后 7 美元/月，或者 59 美元/年。
- 计算器始终免费。

## 自动化架构

| 交给谁 | 做什么 |
|---|---|
| GitHub Actions 定时任务（和现在日报同一套路） | 每天拉 HTS 并比对快照 → 重建有变化的页面 → 部署到 Cloudflare Pages；有变化时给订阅者发提醒邮件 |
| Claude Code，每周一次 | 按 `marketing-loops` 的「每周 SEO 机会扫描」：读 Search Console 数据，找排在 8–20 名的页面，起草改写稿，存到草稿目录等你看；每月跑一次 `seo-audit` |
| Claude Code，按需 | 新增一批税号页时补经验数据的初稿；起草写给线索买方的邮件 |
| 你自己 | 审改写稿、确认发布（技能本身也要求：自动起草可以，自动发布要人批准）；回线索买方邮件；每月对一次账 |

稳定后**每周约 2 小时**：审稿 1 小时，对接买方 1 小时。前两个月每周 8–10 小时。

不要接 `tools/` 下那些要账号授权的集成（CRM、广告、发信平台）。这个项目用不上它们，接了就多一份密钥要管。

## 未来预测

- **6 个月**：技能包本身会继续涨，现在 GitHub 56,037 星，前几名技能各 12–23 万次安装；同类的 claude-seo 在 2026-06 也有 9,461 星。这类方法清单会越来越普及，大家都会做 pSEO，**结果是薄页面更多，Google 打得更狠**。你这个站 6 个月时多半刚开始被收录，有零星流量。
- **12 个月**：能不能活下来，看你有没有攒下数据（每日关税快照、你的经验表）。Google 的规则写得很清楚，「用生成式 AI 批量生成页面而不给用户增加价值」算滥用（scaled content abuse），针对相似搜索词批量建页也算门页滥用（doorway abuse）。有自有数据的工具页风险小，纯文字页风险大。
- **24 个月**：AI 概览对点击率的影响不确定。Seer 的数据显示 2025 年底跌到谷底，2026 年初有回升，但这只是一家公司的样本，而且是相关性数据。我的判断是：计算器和实时数据表会比纯文章撑得久，但也可能被 Google 自己的工具（比如内置的单位换算、汇率）吃掉一部分。**这一点我判断不准。**
- 美国对中国商品的关税变化频繁，这是需求来源，也是风险：哪天政策稳定下来，搜索量会掉（推断）。

## 风险与对策

1. **Google 判定批量内容滥用或门页滥用（平台政策）**：不按「税号 × 国家 × 城市」这种组合铺页面；只出有独有数据的页面，薄的 noindex；每批上线后看两周收录率，收录率低就停下来改模板。
2. **关税数据出错引起纠纷**：每页都链到 hts.usitc.gov 原条目，写上「数据取自 USITC，更新于某日，仅供参考，以报关行为准」；比对脚本发现解析异常时停止发布，不要带病更新。
3. **AI 概览截走点击**：把重点放在计算器和变化记录上，问答式文章少写；用 `ai-seo` 技能争取被 AI 回答引用，至少品牌名能露出来。
4. **线索没人买，或者买方嫌质量差**：表单里设必填项（品类、数量、目标价），过滤学生和随便问问的；先免费试送，拿到反馈再定价。
5. **技能里的商业倾向**：`programmatic-seo` 的平台推荐里有作者的合作方 Ploy，作者自己也写了 Ploy 的教程，文件里有披露。平台按自己情况选，Astro + Cloudflare 就够了。
6. **开发信合规**：照 `cold-email` 的要求带退订行和邮寄地址；用单独的发信域名，不要用主域名。
