**结论：通用表单 API 不值得做，只值得花 2 周、100 美元以内验证一个窄版本：给 B2B 外贸独立站用的「询盘表单 + AI 筛垃圾询盘 + 线索打分」，从 wordpress.org 插件目录拿流量。** Web3Forms 的收入是真的：TrustMRR 页面上 MRR $43,692、3,174 个活跃订阅，平均每个订阅每月约 $13.8（推断，用这两个数相除）。但这个品类已经很挤，还在降价：Formspree、Forminit（原 Getform，2026 年 1 月改名）、Basin、Formspark、Formgrid、Netlify Forms 都在做，新来的 splitforms 只卖 $5/月。你没有开发者渠道，做通用版拿不到流量。你的优势是懂外贸站的询盘：垃圾多、要筛客户、要马上回复，这个细分还没有人专门做。关 1 勉强能过：已经有人在付费；渠道不是现成的，要靠插件目录和 SEO 去建，所以第 30 天的关要卡严。

## 怎么做

1. **第 1–2 天：确认需求和名字**。打开 wordpress.org 上 inquiry、quote 标签下的插件，把差评和支持帖里的抱怨抄下来（垃圾询盘、收不到邮件、没有 WhatsApp 提醒）。买一个 .com 域名，约 $12。
2. **第 3–6 天：做后端**。用 Claude Code 写一个 Cloudflare Worker，提供 `POST /f/<表单ID>` 这个接口。存储用 D1，免费档每天能写 10 万行。每条提交按四个信号打分：发件邮箱是公司域名还是免费邮箱、IP 所在国家和填的国家是否一致、内容的语言、有没有「SEO 服务」「贷款」这类垃圾话术。前三个用规则判断，最后再用便宜的模型给一个 A/B/C 分级和一句摘要。通知邮件用 Resend 发，免费档每月 3,000 封、每天最多 100 封；同时推 Telegram 或 Slack。Workers 付费档每月 $5。
3. **第 7–9 天：做前端和收款**。前端是一段能直接嵌进 HTML 的表单代码，再加一个 WordPress 插件（短代码加设置页），提交 wordpress.org 审核，一般要等几天到两周。接 Creem 订阅，产品里必须能自己取消订阅（Creem 审核要求）。
4. **第 10–14 天：做内容**。写 5 篇对比页和教程：「Web3Forms 替代品（B2B 版）」「Basin 和本产品对比」「WordPress 外贸站怎么挡垃圾询盘」「Astro / Webflow 询盘表单」「询盘表单该放哪些筛选字段」。

| 项目 | 服务 | 费用（前 3 个月） |
|---|---|---|
| 域名 | 任意注册商 | ~$12 |
| 接口和数据库 | Cloudflare Workers 付费档 + D1 | $5/月 × 3 = $15 |
| 通知邮件 | Resend 免费档，超量后 Pro $20/月 | $0–20 |
| AI 打分 | 便宜模型的 API，按量计费 | ~$10（推断：每条几百个 token） |
| 收款 | Creem，没有月费 | 按笔抽成 |
| 插件分发 | wordpress.org | $0 |
| **合计** | | **约 $40–60，留 $40 机动** |

## 用在哪些场景

- **印度、土耳其、越南、东欧的中小工厂**：自己用 WordPress 建了英文站，每天收到几十条「SEO 服务」「贷款」类垃圾询盘，真询盘被淹掉。
- **帮外贸企业建站的海外小代理公司**：一个人维护 20 个客户站，想用一个后台统一收询盘、按质量转给各个客户。
- **用 Astro、Hugo、Webflow 建 B2B 产品站的独立开发者**：没有后端，又想要比 Formspree 更懂 B2B 的筛选（国家、公司邮箱、采购量字段）。
- **在 Google Ads 上投询盘的工厂**：想知道每个关键词带来的是 A 级还是 C 级询盘（提交时记下 UTM 参数，按来源统计分级）。

## 能实现什么

- 第 30 天：插件过审上架，装机 50–150 个（推断：新插件没有评分时，每天几个安装是常见水平），对比页开始有收录。
- 第 90 天：活跃装机 300–800 个，付费转化 2–4%，大约 10–30 个付费用户，MRR $100–400（推断，按 $9–29 的档位算）。
- 依据：Web3Forms 用约 5 年做到 41.2 万用户、3,174 个付费，免费转付费不到 1%（推断，按页面上的两个数相除）。窄版本要把转化率做到通用版的几倍，才养得活。

## 客户画像

- **谁付钱**：每月询盘 50 条以上、垃圾占一半以上的 B2B 网站主，还有帮他们建站的代理公司。
- **在哪找到他们**：wordpress.org 的插件搜索（inquiry、quote、contact form spam）、搜「B2B inquiry spam」的 Google 用户、外贸建站相关的论坛（Reddit 的 r/Wordpress、r/b2bmarketing，只看不发广告）。
- **现在怎么解决**：用 reCAPTCHA 加人工看，或者用 Basin Pro。Basin Pro 有按地区、语言过滤，年付折合每月 $30.62，只有 250 条提交的 Starter 档每月 $12.50。也有人干脆用 Alibaba 上的询盘管理。
- **愿意付多少**：通用表单的价位在 $5–30/月（splitforms $5、Web3Forms Pro $149/年、Formspree Personal $15、Forminit Pro $16）。B2B 筛询盘带来的价值更直接（推断），定在 $9–29 有说服力。

## 自动化架构

- **交给 Claude Code / Codex**：写和改 Worker、插件、对比页初稿；每周读一遍支持邮件，起草回复。
- **交给 Cloudflare 和定时任务**：接收提交、打分、推送都在 Worker 里完成。每天定时检查 Resend 的退信率和投诉率，超标就自动停掉那个表单。每周给付费用户自动发一份「本周 A/B/C 级询盘统计」。
- **仍要人做**：处理滥用（有人拿表单接口群发垃圾）、回复 wordpress.org 的支持帖（官方要求作者回复）、偶尔的账单纠纷。
- **稳定后每周约 2–3 小时**。

## 未来预测

- **6 个月**：表单后端的价格还会往下走，splitforms 已经卖 $5/月，Web3Forms 2026 年 1 月把 Pro 的额度从每月 2 万条砍到 1 万条。通用版靠价格竞争会更难，细分版本还有空档（推断）。
- **12 个月**：表单工具都会加上 AI 筛垃圾（Basin 已经有按地区、语言过滤），「AI 分级」本身会变成标配。到时你要靠 B2B 专用的字段、来源统计和代理公司多站管理守住（推断）。
- **24 个月**：这个类目会分成两头，一头是免费或极便宜的通用接口，一头是绑在 CRM 或建站平台里的功能。独立的窄产品大概率在 MRR $1–3k 停住，适合当成一个小项目养着，或者卖掉（推断，依据是 Formspark、Formcarry 这类同类小产品多年都是小体量）。这一条最不确定。

## 风险与对策

1. **平台政策风险：被拿来群发垃圾邮件，发信域名被封**。对策：通知邮件只发给账户里验证过的收件邮箱，不提供「给提交人自动发营销邮件」的功能；用单独的子域名发信；Resend 的投诉率接近 0.3% 时自动停用那个表单。
2. **平台政策风险：wordpress.org 拒审或下架**。插件目录禁止插件里内嵌垃圾广告、不经同意上报数据，免费功能也要真能用。对策：先读[插件准则](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/)，免费档功能完整，只把 AI 分级做成付费的远程服务，并在说明里写清楚会把哪些数据发到外部服务。
3. **大厂一更新就把你的卖点做掉**（Basin、Formspree 加上 AI 分级）。对策：只做外贸站特有的东西（采购量和国家字段、UTM 来源统计、代理多站管理），第 30 天的关不过就直接砍掉。
4. **收款风险**：Creem 把「服务类」和「API 转售」列为限售。对策：开户时就写明是自研 SaaS，不碰代写、代运营这类服务。

## 怎么收钱

- **能收**。卖的是自研 SaaS 订阅，属于 [Creem](https://www.creem.io/pricing) 允许的「软件和 SaaS」。费率按页面核对过：每笔 3.9% + $0.40，没有月费，支持订阅和按量计费，每月 1 号、15 号打款到银行账户或 USDC 钱包。定价页没写卖家可以在哪些国家，要先问客服确认大陆个人能不能开户（仓库主人之前的记录是两家都支持大陆个人，这次页面上没看到原文）。
- **备选 [Dodo Payments](https://dodopayments.com/pricing)**：美国卡 4% + $0.40，非美国卡再加 1.5%，订阅再加 0.5%。非美国企业 SWIFT 打款每笔 $25，FAQ 里说 $1,000 以下的打款收 $5。客户多是印度、土耳其这类非美国卡，所以 Dodo 每笔约 6% + $0.40，比 Creem 贵。
- **$9 月付的实际到手**：Creem 抽 $0.75（约 8.3%）。所以要主推 $79 年付，Creem 抽 $3.48（约 4.4%）。
- **禁售清单核对**（[Creem 审核和禁售清单](https://docs.creem.io/merchant-of-record/account-reviews/account-reviews)）：表单 API 不在禁售里。要注意三个限售类别：「各类服务（营销、设计、建站、咨询）」「API 转售」「在邮件通讯里卖广告」。所以别把产品写成「帮你做外贸营销」，也别卖第三方 API 的额度。另外清单里有「流量和互动服务」是禁售，落地页不要出现「提高询盘量」「刷询盘」这种说法。
- 回款进万里汇，提现人民币 0.7% 封顶。Stripe 不收大陆商户；Lemon Squeezy 新项目别用。

## 合规红线

- **代存别人网站访客的个人信息（GDPR）**
  - 能做：作为数据处理方，替网站主接收和保存询盘。
  - 不能做：把询盘里的邮箱拿去营销，或者转卖、共享。
  - 怎么做才行：落地页放隐私政策和数据处理协议（DPA）模板；默认保存 1 年，可以设置更短；提供删除和导出；写清楚用了哪些子处理方（Cloudflare、Resend、AI 接口）。原文：[GDPR 第 28 条（处理方）](https://gdpr-info.eu/art-28-gdpr/)。
- **发通知邮件**
  - 能做：把询盘转发给账户主人，属于事务邮件。
  - 不能做：用你的发信域名给提交询盘的人发营销邮件。
  - 怎么做才行：配齐 SPF、DKIM、DMARC，投诉率低于 0.3%。如果要做「自动回复询盘人」，只写一句「已收到」，不夹带广告。原文：[Gmail 发件人要求](https://support.google.com/a/answer/81126)。
- **你自己给潜在客户发开发信**
  - 能做：用公司邮箱逐个给美国的公开商务邮箱写信。
  - 不能做：不写真实发件人和实体地址，或者不给退订。
  - 怎么做才行：守 [CAN-SPAM](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business)，10 个工作日内处理退订。加拿大守 CASL，要先有同意，先不发；欧盟按正当利益做平衡测试、留记录，德国、奥地利先不发。
- **WhatsApp 提醒**（如果以后要加）
  - 能做：用官方 Business Platform，只发给自己同意接收的网站主。
  - 不能做：用非官方工具给询盘人群发。
  - 怎么做才行：只能发给明确同意过的号码。2025-07-01 起按条计费，24 小时窗口外只能发模板消息。第一版先用 Telegram 或 Slack 推送。原文：[WhatsApp 定价](https://developers.facebook.com/docs/whatsapp/pricing)。
- **开源许可证**：自己写就不涉及。如果拿开源的表单后端改成托管版来卖，先看许可证档位：AGPL 托管要公开改动，BUSL、Elastic、SSPL 这类不能托管来卖。
