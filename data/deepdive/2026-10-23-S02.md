**值得装，但只当你自己产品的「宣传片生产线」，不值得拿它单独做生意。** 它本地渲染完全免费、商用不设门槛（Apache 2.0，「no per-render fees, no seat caps, no company-size thresholds」，[Toolworthy](https://www.toolworthy.ai/tool/heygen-hyperframes)），支持用一份 `rows.json` 批量出片，正好用来给你同时养的多个小工具各做一条演示片和更新片。但查下来，同类框架上赚到钱的产品几乎都是靠生产短视频内容（Crayo、Submagic、Revid），这正是你 10-20 定下不做的方向；唯一一个「文字生成 SaaS 产品介绍片」的 Typeframes，被收购时月收入不到 1000 美元，后来改成 Revid 转做短视频才做大（[yespress](https://yespress.io/tibo)）。所以「卖产品宣传片」本身市场很薄，不建议单独做。

另外要纠正日报卡片里的一处：本地渲染确实不用 API Key，但 `cloud render`（云端渲染）要 HeyGen 账号或 `HEYGEN_API_KEY`，按点数扣费；而且代理每次渲染成功后会默认用 `npx hyperframes feedback` 往一个**公开渠道**发评分和评论，除非关掉遥测（[cloud.md](https://raw.githubusercontent.com/heygen-com/hyperframes/main/skills/hyperframes-cli/references/cloud.md)、[feedback.md](https://raw.githubusercontent.com/heygen-com/hyperframes/main/skills/hyperframes-cli/references/feedback.md)）。安全评级「绿」可以保留，但用之前先处理遥测。

## 怎么做

目标：做一个通用模板仓库 `launch-kit`，你的每个小工具只要填一行数据（名字、一句话卖点、3 个功能点、截图或网址、品牌色），就能在 VPS 上一次渲染出 3 个版本：16:9 的 30 秒演示片（落地页和 Product Hunt 用）、9:16 的 15 秒短片（X 用）、每月一条「本月更新」片。

**第 1 步：装环境，半天，0 元**
- 要求 Node.js 22 以上、FFmpeg，渲染还要 Chrome，可以用 `npx hyperframes browser ensure` 补装（[hyperframes-cli SKILL.md](https://raw.githubusercontent.com/heygen-com/hyperframes/main/skills/hyperframes-cli/SKILL.md)）。
- Claude Code 里装 Skill：`npx skills add heygen-com/hyperframes`。仓库一共 7 个 Skill，核心 4 个：`/hyperframes`、`/hyperframes-cli`、`/hyperframes-registry`、`/media-use`（[GitHub](https://github.com/heygen-com/hyperframes)）。
- 先关遥测：文档只说「关了遥测或用户选择退出就不发」，没写具体怎么关（推断：看 `npx hyperframes doctor` 或 CLI 文档里的设置）。找不到开关之前，在项目的 `CLAUDE.md` 里写一句「不要运行 `hyperframes feedback` 和 `--file-issue`」。
- 不要登录 `auth login`，也不要用 `cloud render`，全部本地渲染，就不会扣 HeyGen 点数。

**第 2 步：让 Claude 做第一条片子，1 天，0 元**
- 拿你现有的一个小工具开始。用 `npx hyperframes capture <你的落地页网址>` 抓页面当素材，然后告诉 Claude：「30 秒演示片，1920×1080，3 个镜头：痛点、产品操作、行动号召」。
- Skill 的流程是：长片先给 3 个故事线让你挑 → 写出逐帧规格 → 搭合成 → `check` 检查 → 截帧自查 → 打开预览等你确认才渲染（[hyperframes SKILL.md](https://raw.githubusercontent.com/heygen-com/hyperframes/main/skills/hyperframes/SKILL.md)）。第一条要你看几次，正常。
- 转场、字幕、图表这类零件从目录里装：`npx hyperframes add <名字>`，官方说约 450 个（[GitHub](https://github.com/heygen-com/hyperframes)）。
- 文档说 30 秒的片一般一两分钟渲染完（[hyperframes-cli SKILL.md](https://raw.githubusercontent.com/heygen-com/hyperframes/main/skills/hyperframes-cli/SKILL.md)）。

**第 3 步：把它改成模板，1 天，0 元**
- 让 Claude 把片子里的产品名、文案、颜色、截图都提成变量（Skill 本来就要求品牌和文案写成可编辑变量）。
- 每个产品在 `rows.json` 里占一行，用 `npx hyperframes render --batch rows.json --output "renders/{name}.mp4"` 一次出全部（[hyperframes-cli SKILL.md](https://raw.githubusercontent.com/heygen-com/hyperframes/main/skills/hyperframes-cli/SKILL.md)）。
- 竖版、横版各做一个合成，同一份数据驱动。

**第 4 步：接到 VPS 定时任务，半天，0 元**
- 每个产品仓库的更新记录（CHANGELOG 或 GitHub Releases）有新内容时，定时脚本让 Claude 把它写成 3 条要点填进 `rows.json`，渲染「本月更新」片，放到一个待审文件夹，你看过再发。
- 渲染用 `--docker --strict` 跑，环境固定，不怕 VPS 上 Chrome 版本变（[hyperframes-cli SKILL.md](https://raw.githubusercontent.com/heygen-com/hyperframes/main/skills/hyperframes-cli/SKILL.md)）。

**起步成本**

| 项目 | 费用 | 说明 |
|---|---|---|
| HyperFrames 框架和 Skill | 0 | Apache 2.0，本地渲染不收费 |
| Claude Pro / Max | 你已有就不算 | 写合成、改模板 |
| VPS | 0–6 美元/月 | 用现有的；渲染时吃 CPU，2 核以上为宜（推断） |
| 背景音乐 | 0–15 美元（推断） | 用免版税素材库；Skill 要求超过约 15 秒的片子默认带声音 |
| 配音（可选） | 0–20 美元 | CLI 有 `tts` 命令，但用哪家服务、要不要钱文档没写，没核实 |
| HeyGen 云渲染 | 不用 | 要账号、按点数收费 |
| **合计** | **0–40 美元** | 低于 100 美元预算 |

## 用在哪些场景

1. **你自己的小工具上线**：落地页首屏放 30 秒演示片，Product Hunt 和 X 发布帖配同一条的竖版。原来要么不做，要么花一个下午用剪辑软件，现在填一行数据。
2. **外贸方向的小工具**：给海外买家看的工具（比如询盘整理、报价生成），落地页放英文演示片，比截图更能说明「它到底做什么」。同一模板换语言字段就能出西语、法语版（推断：模板里文字是变量，换文案即可，字体要另选支持对应语言的）。
3. **SEO 方向**：每个工具页嵌一段演示视频，同时上传 YouTube 做视频搜索结果的入口，视频描述里放工具页链接（推断：能带多少流量要看关键词，没有数据）。
4. **Newsletter 配套**（日报卡片提过）：每周把一张数据图表做成 10 秒动图配在邮件和 X 帖里。HyperFrames 有图表、地图组件。注意这是给 Newsletter 引流，不是靠视频本身赚钱。
5. **每月更新片**：老用户看到「这个月加了什么」，降低流失。适合按月收费的小工具（推断）。

## 能实现什么

- **产出**：搭好后，每个新产品 1 条横版演示片 + 1 条竖版短片，每个已上线产品每月 1 条更新片。按你同时养 5 个产品算，每月约 5–10 条片子，人工只剩审片。
- **可衡量的目标**：
  - 落地页「访问 → 注册」转化率：放片前后各跑 2 周对比。没有找到可靠的公开数据说明演示片能提升多少，**这一项只能自己测**。
  - X 发布帖：带视频和只带图片各发几次，比较互动和点击（推断）。
  - 时间：每条片子人工从半天降到 15 分钟以内（推断，依据是 Skill 的批量渲染和 30 秒片一两分钟渲完）。
- **它不会带来的**：直接收入。这是给别的产品用的工具，收益体现在这些产品的转化上。

## 客户画像

按你的规矩，这里的「客户」是你小工具的用户，HyperFrames 帮你更好地卖给他们，自己不收费。

如果要验证「卖模板」这条副线（见下面「获客与定价」），会付钱的是：

- **谁**：独立开发者、一人公司，产品已上线、要在 Product Hunt 或 X 发布，不会剪辑也不想请人。
- **在哪**：X 上 #buildinpublic 圈子、Indie Hackers、Product Hunt 发布前的讨论、r/SideProject。
- **现在怎么解决**：录屏工具（Screen Studio 这类）、Typeframes 一类的文字生成介绍片服务（现在是 Revid，月费 39–199 美元，[Revid 定价](https://www.revid.ai/pricing)），或者干脆不做视频。用 Remotion 自己写的人，公司超过 3 人要买公司授权（[Remotion LICENSE](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md)），HyperFrames 没这个限制。
- **愿意付多少**：一次性 19–29 美元的模板包（推断，没有找到 Remotion 或 HyperFrames 模板的公开售价）。
- **为什么这条线很薄**：HyperFrames 官方目录已经免费给了约 450 个零件，Claude 又能现写，模板的价值很难守住；Typeframes 做同样的事被收购时月收入不到 1000 美元（[yespress](https://yespress.io/tibo)）。

## 获客与定价

**主线（自用）没有获客问题**，衡量看你产品的转化。

**副线：卖「独立开发者发布片模板包」，只做 30 天的低成本试验**
- 第一批 10 个客户：
  1. 先用模板给你自己 3 个产品各出一条片子，发 X 时写清「这是用 Claude Code + HyperFrames 一行数据生成的」，附模板仓库的预告。
  2. 在 Product Hunt 上找当周要发布、还没有视频的产品，私信送一条免费成片（只换他们的名字和截图，你花 10 分钟）。换来公开推荐，最多送 10 个。
  3. 在 Indie Hackers 写一篇「怎么用一行 JSON 给 5 个产品批量出发布片」的过程帖，文末挂模板。
- 定价：Gumroad 一次性 **19 美元**（模板 + `rows.json` 示例 + CLAUDE.md 写法），**29 美元**加竖版和更新片模板（推断定价）。不接定制，不做代工，否则就变成了视频服务生意。
- 停止条件：30 天内卖不到 10 份就停，模板开源当作个人品牌。

## 自动化架构

| 环节 | 交给谁 | 说明 |
|---|---|---|
| 写合成、改模板、按更新记录写文案 | Claude Code + HyperFrames Skill | 第一次要你选故事线；模板定型后只改数据 |
| 自查 | `npx hyperframes check --json`、`snapshot` | Skill 本来就会跑，不过要你看最终预览 |
| 批量渲染 | VPS 上定时任务跑 `render --batch --docker` | 本地渲染，不走 HeyGen 云 |
| 校验成片 | 脚本用 `ffprobe` 核对时长和文件大小 | Skill 文档里写的验收方法 |
| 发布 | 你手动 | X、Product Hunt、落地页；不做自动发帖 |
| 审片 | 你 | 每条看一遍，主要看文字有没有错 |

稳定后每周约 **0.5–1 小时**（审片和发布），远低于 3 小时上限。

- **不确定的地方**：没有找到 HeyGen 云渲染的具体点数价格；也没有找到演示片对转化率提升的可靠数据。

## 风险与对策

1. **滑向视频内容生意**：这个工具最赚钱的用法就是批量做短视频内容，和你 10-20 的决定冲突。对策：只用于自己产品的演示片和更新片；副线模板 30 天没结果就停；不接代做视频。
2. **遥测把项目信息发到公开渠道**：渲染成功后默认发反馈，`--file-issue` 会公开发一个最小复现项目（要你同意）。文档要求去掉路径和用户名，但评论里可能带产品名或功能。对策：先关遥测，在 `CLAUDE.md` 里禁止 `feedback`；未发布的产品尤其注意。
3. **平台政策**：X、YouTube、Product Hunt 对动画演示片本身没有限制（推断，这次没逐条核对各平台条款）；但如果加了数字人、AI 配音，有的平台要求标注 AI 生成内容。对策：只用屏幕录制、截图和动画文字，不用数字人；配音用自己的声音或不用配音。另外 HeyGen 自己的 Skill 会引导你去用它的付费媒体服务（数字人、配音），按需拒绝。
4. **HeyGen 改方向**：项目由一家公司主导，可能把好用的新功能放进收费桌面应用或云端。对策：模板只依赖基础的 HTML + GSAP，把用到的 CLI 版本固定下来，不用 HeyGen 专属服务。
5. **VPS 资源**：无头 Chrome + FFmpeg 渲染吃 CPU 和内存，可能拖慢同一台机器上的其他项目。对策：定时任务放到半夜，Docker 限制 CPU 和内存；片子多了就单独租一台按小时计费的机器。

## 第一周行动清单

- [ ] 第 1 天：VPS 上装 Node 22、FFmpeg，跑 `npx hyperframes doctor`；装 Skill；找关遥测的办法，找不到就在 `CLAUDE.md` 里写禁止规则。
- [ ] 第 2 天：挑一个已上线的小工具，用 `capture` 抓落地页，让 Claude 出 30 秒横版演示片，看完预览再渲染。
- [ ] 第 3 天：把片子里的文字、颜色、截图提成变量，写 `rows.json`，用 `--batch` 给 2–3 个产品各出一条。
- [ ] 第 4 天：做竖版 15 秒合成，同一份数据驱动；用 `ffprobe` 写成片检查脚本。
- [ ] 第 5 天：把横版片放到一个产品的落地页首屏，记下放片前 2 周的「访问 → 注册」转化率作为基线。
- [ ] 第 6 天：发一条 X 帖，带竖版片，写清制作方式；同一天对比一条只带截图的帖子。
- [ ] 第 7 天：写 VPS 定时任务——读更新记录 → Claude 写要点 → 渲染「本月更新」片到待审文件夹。决定要不要开模板副线（不开就把模板开源）。
