**结论：find-skills 本身不能拿来卖钱，但值得研究：它就是代理的「应用商店搜索」，代理会按它的规则替用户挑 skill。真正能赚钱的是反过来用：做一套外贸 B2B 方向的免费 skill，挤进它的推荐结果，把装了的人引到你的付费工具上。** skills.sh 上 SEO 类已经很挤（coreyhaines31 的 seo-audit 23.8 万次安装），Amazon 类被 nexscope 一家铺了 53 个；但搜「export」「alibaba」「inquiry」，几乎找不到讲询盘、报价、找进口商的 skill，这块是空的，又正好是你做过的行当。直接卖 skill 文件赚得很少（Agensi 自己公布的头部单品才 436 美元），所以只把 skill 当获客入口，钱从后面的小工具来。

## 先弄清 find-skills 怎么挑 skill（决定你的 skill 能不能被推荐）

打开 SKILL.md 核对过，它让代理按这个顺序找：

1. 先看 skills.sh 榜单，再用 `npx skills find <关键词>` 搜（可加 `--owner` 只看某个作者）。搜索只匹配 skill 的**名字和 description**。
2. 推荐前要核实：**安装量最好过 1K**，来源可信（vercel-labs、anthropics 这类），**GitHub 星数低于 100 要存疑**。
3. 找不到就建议用户 `npx skills init` 自己写一个。

这对你的意思是：

- **新 skill 起步时进不了它的推荐**。门槛是 1K 安装加 100 星，第一批安装量只能靠自己的渠道拉（见「获客」一节）。
- **description 要写用户会搜的词**，比如 "export inquiry reply"、"RFQ quotation"、"find importers"，别写产品名。
- 上架不用申请：skills.sh 收录所有能用 skills CLI 装上的公开 GitHub skill，排名看 CLI 上报的去重安装数（每小时去重一次），有异常检测防刷量；所有合作方安全审计都不过的会被下架。frontmatter 的 YAML 写错会被**悄悄跳过**，多 skill 仓库要放成 `skills/<名字>/SKILL.md`，根目录别放 SKILL.md。

## 怎么做

方案：开源一套「外贸询盘到成交」skill 包（MIT），配一个付费小工具。

| 步骤 | 做什么 | 用什么 | 花费 | 用时 |
|---|---|---|---|---|
| 1 | 定 6 个 skill：`inquiry-qualify`（询盘判真假、打分、排优先级）、`inquiry-reply`（按买家类型回第一封）、`rfq-quotation`（按 FOB/CIF/DDP 出报价单和条款）、`importer-prospecting`（用公开来源找目标国进口商、写开发信）、`follow-up-sequence`（报价后跟进节奏）、`trade-show-leads`（展会名片整理和跟进） | 你自己的外贸经验 + Claude Code 起草 | 0 | 2 天 |
| 2 | 建仓库 `你的名字/export-skills`，`npx skills init` 生成模板，每个 skill 附 1～2 个示例询盘和输出样例 | GitHub、skills CLI（要 Node 22.20 以上） | 0 | 1 天 |
| 3 | 自己跑 `npx skills add 你的名字/export-skills` 看完整输出，确认 6 个都装上了 | 本地 | 0 | 半天 |
| 4 | 做付费工具：一个网页，贴进询盘邮件，返回「真实度评分 + 公司背景核查结果（官网、域名注册时间、公开商业登记）+ 回复草稿」。skill 里写「要做背景核查，可调用 xxx API（需要 key）」，免费版只出评分 | VPS 上跑 Python + 你常用的模型 API；Stripe 或国内的面包多收款 | 域名约 12 美元/年（推断）；模型 API 先充 30 美元；VPS 用现有的 | 4～5 天 |
| 5 | 中文版同步：同一套 skill 写中文 description，再发到 OpenClaw 的 ClawHub（腾讯 SkillHub 是 ClawHub 的国内镜像，发了 ClawHub 就会被同步） | 同上 | 0 | 1 天 |
| 6 | 高级版：「按行业的报价模板 + 30 套开发信」打包，挂 Agensi（作者分 70%，人工审核 24～48 小时，要做 KYC） | Agensi | 0 | 半天 |

## 用在哪些场景

1. **中小外贸工厂的业务员**：每天几十封阿里国际站、官网询盘，分不清哪封是真采购、哪封是同行套价或骗样。装了 `inquiry-qualify` 后在 Claude / Codex 里粘贴就能排序。
2. **刚起步的 SOHO 外贸人**：没有客户，要从零找进口商。用 `importer-prospecting` 按国家和 HS 编码列出公开名录里的公司，再批量写开发信。
3. **做独立站 + Google 询盘的 B2B 卖家**：询盘少但单价高，最怕回复慢、报价条款写错。`rfq-quotation` 出带贸易术语和付款方式的报价单，减少来回。
4. **跨境电商转做 B2B 批发的人**：熟悉 Amazon 不熟悉 B2B 报价。现在只有 nexscope 那套 Amazon skill，B2B 这一块没人写。

## 能实现什么

- **安装量**：参照同类，nexscope 的 Amazon 细分 skill 大多 1,100～1,700 次安装，头部那个 7.8 万次。外贸 B2B 受众更窄，**推断**：3 个月主 skill 1,000 次安装（过了 find-skills 的门槛），6 个月整包合计 5,000 次。
- **星数**：3 个月 100 星（过了 find-skills 的「存疑」线），这是被代理推荐的前提。
- **付费工具**：**推断**按 1～2% 的安装者转成付费，5,000 次安装约 50～100 个付费用户，按 19 美元/月算月收入 1,000～1,900 美元；保守一点按一半算。
- **高级包**：别指望。Agensi 公布的数字里，7 美元的 keyword-research 卖了 89 次，作者约得 436 美元；这还是平台自己挑出来展示的。高级包只当顺手的小收入。

依据：skills.sh 搜索结果里的安装数（10-27 打开）；Agensi 公布的单品数字（自报、未审计）。

## 未来预测

- **6 个月**：skill 数量继续暴涨（Agensi 上线 3 个月时 2,000 个，现在自称 1.4 万个），**通用类会更挤，有行业经验的垂直 skill 才看得见**。find-skills 稳坐 skills.sh 第 1（410 万次安装，从 2026-01-26 首次收录算起），代理按它的规则挑 skill 的情况还会继续。
- **12 个月**：**推断**排名会更看重安全审计和真实使用，而不只是安装数：Vercel 已经在每次安装时用 Claude 自动审查，所有审计都不过的会下架；find-skills 自己的页面上，Snyk 审计也只给了「warn」。带外部 API 调用的 skill 审核会更严，要提前把联网行为写清楚。
- **24 个月**：**不确定**。一种走向是官方商店（Anthropic 插件市场、OpenAI 等）加上收费功能，第三方市场被边缘化；另一种是 skill 一直免费，钱只能从背后的工具和数据来。两种情况下「免费 skill 引流、付费工具变现」都能用，这也是选它而不是直接卖 skill 的原因。
- 现成例子：coreyhaines31 的 marketingskills（5.67 万星，52 个 skill）在 README 里推自己的代理公司、培训课和赞助商；nexscope 的 53 个 Amazon skill 全部免费，链接都带 `co-from=github` 引回自家数据 API。两家都是同一个路子。

## 风险与对策

1. **平台规则变化**：skills.sh 改排名算法，或者 find-skills 改推荐门槛，你的曝光一夜归零。对策：曝光渠道别只靠它，福步、知乎、小红书和自己的邮件列表同时做；同时上 Claude Code 插件市场和 ClawHub（腾讯 SkillHub 首周就有 87 万次下载）。
2. **安全审计把你拦下**：skill 里调外部 API、带脚本，容易被 Snyk 一类工具标黄甚至下架。对策：免费 skill 只放纯指令，不带可执行脚本；API 调用写在说明里，让用户自己配 key；`allowed-tools` 不申请 Bash。
3. **被抄**：MIT 协议下别人可以直接搬走，腾讯 SkillHub 就整站镜像过 ClawHub（IT 之家有报道）。对策：免费 skill 本来就是拿来传播的，护城河放在付费工具的核查数据和行业模板上，不开源这部分。
4. **背景核查踩合规线**：抓第三方网站或商业登记信息，可能违反对方服务条款或隐私法规。对策：只用官网、WHOIS、各国官方公开登记这类公开来源，不存个人数据，只存核查结果，用户删除时一起删。
5. **刷量冲动**：自己刷安装会被异常检测抓到。对策：不刷；早期的安装数只靠真实用户和渠道帖。
