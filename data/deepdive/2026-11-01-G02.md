**结论：Orkas 本身不值得当成赚钱项目，但可以花半天试用，拿它做一个「外贸独立站 AI 搜索体检报告」的定价小产品。** 这个方向值得试，原因有两条：它内置的 SeoGeoAgent 输入一个网址就能出技术审计、内容质量、Core Web Vitals、GEO 可引用性和按优先级排的修复清单，正好是这个产品要交付的东西；同类体检在网上的公开报价是 99–499 美元一次。不值得把整套流程押在 Orkas 上，原因也有两条：一是它要求电脑开着、Orkas 在运行，定时任务才会跑，放不上 VPS 托管；二是项目还很早期（第三方评测 CodePick 直说"不适合要求生产稳定的流程"），而你用 Claude Code 加 VPS 定时任务能做到同样的事。建议的用法是：先用 Orkas 把报告模板和流程跑通，跑通以后迁到 Claude Code，Orkas 只留着当桌面上的操作台。

## 怎么做

1. **装好、试跑（第 1 天，0 美元，2 小时）**：Mac 或 Windows 下载安装包（第三方指南写的版本是 v2026.9.11）；Linux 只能用源码跑，要 Node 22.12+ 和 glibc 2.34+，首次启动还要下载大约 95 MB 的嵌入模型。先用送的 500 积分试，不填自己的密钥。
2. **换成自己的模型密钥（第 1 天，约 10–20 美元充值）**：在设置里填 Claude 或 DeepSeek 的 API Key。官方说用自带密钥时 Orkas 不加价，模型调用从本机直接发到模型厂商。正式出报告要用自己的密钥，不要用 Orkas 积分，因为积分的单价不透明（官网写的是每百万输入 token 100–300 积分）。
3. **做报告模板（第 2–3 天，0 美元，4 小时）**：建一个 Project，在规则里写死报告结构：AI 搜索可见度（拿 20 个行业问题去问 ChatGPT、Perplexity，看结果里有没有引用这个站）、技术问题、内容缺口、llms.txt 和 FAQ schema 有没有做、前 10 条修复建议。SeoGeoAgent 出审计，DeepResearcher 找竞品，PptMaker 或 OfficeWorker 排成 PDF。
4. **用自己的站和 5 个公开外贸站试跑（第 3–4 天）**：记下每份报告花多少钱、多少分钟，人工把把关需要的时间压到 20 分钟以内。
5. **落地页和收款（第 4–5 天，约 15 美元）**：Cloudflare Pages 免费放一个单页，买一个域名大约 10 美元，Lemon Squeezy 或 Stripe 收款（按成交抽成，没有月费）。客户在表单里只填网址、行业和 3 个竞品网址，不开会、不做定制。
6. **迁移到 Claude Code（第 2–4 周）**：流程稳定后把 Orkas 里的规则写成一份提示词，放到 VPS 上：客户付款触发 webhook，Claude Code 出报告，自动发邮件给你审，你审过再发给客户。Orkas 是 MIT 许可证，内置专员的做法可以照着改。

## 用在哪些场景

- **中小外贸工厂的独立站**：站是外包建的，老板想知道"客户在 ChatGPT 上问供应商的时候，会不会提到我"，但不想签 1,500 美元起的代理商合同。
- **Shopify 小卖家**：Orkas 有 Shopify 连接器，还有 ECommerceWriter 和 ECommerceReviewer 两个专员，可以在体检之外顺带重写商品页 FAQ，做差评原因分析，作为加价项。
- **SEO 自由职业者和小建站公司**：他们拿你的报告去提案，当白标外包；他们不愿自己搭流程。
- **你自己的项目矩阵**：每个新的小站上线前先跑一次，这本身就能省掉人工检查的时间。

## 能实现什么

- **3 个月目标（推断）**：每月卖出 10–30 份 49 美元的报告，月收入 500–1,500 美元；每份人工审核 20 分钟，每周 3 小时以内。
- **依据**：GTM 80/20 汇总的公开报价里，自动扫描档是 99–499 美元，最便宜的产品化审计是 Citant.ai 的 440 美元；OneTimeGEO 卖 297/597/997 美元三档的一次性 GEO 服务，自称交付过"500+ 份审计"，但只有 3 条评价。这些都是卖家的标价，**没有看到成交数据**。所以你定 49 美元，靠的是价格低，不是靠需求已经被证明。
- **流量**：落地页靠两样东西拿自然流量：一是"免费出前 3 条问题"的引子，二是你自己写的"某行业外贸站 AI 可见度对比"系列文章。推断前 3 个月每月 500–2,000 次访问。

## 客户画像

- **谁付钱**：年营业额几百万到几千万人民币的外贸工厂老板或外贸经理，有英文独立站，每年在 Google Ads 或 SEO 上花几万块。
- **在哪里找**：外贸论坛（福步）、知乎和小红书的"外贸独立站"话题、LinkedIn 上的外贸经理，以及 Shopify 卖家群。
- **现在怎么解决**：要么找建站公司按年付 SEO 维护费，要么自己用 Ahrefs、Semrush（月费 100 多美元起），但这两家都不直接回答"AI 会不会推荐我"。
- **愿意付多少（推断）**：几十美元的诊断报告不用走审批，老板自己掏钱就能买；超过 300 美元就要对比几家方案。

## 获客与定价

**第一批 10 个客户：**
1. 挑 20 个外贸行业关键词（例如 "custom silicone parts manufacturer"），在 ChatGPT 和 Perplexity 上问一遍，把被推荐的供应商和没被推荐的整理成一篇对比文章，发到知乎和 LinkedIn。
2. 给 30 个没被推荐的独立站免费跑一份精简版报告（只给前 3 条问题），通过网站留的邮箱发过去。开发信用 Orkas 的 Gmail 连接器起草，保持默认的"发送前确认"。
3. 在外贸社群里发 5 份打码的样本报告。
4. 联系 3 家小建站公司，给他们白标价。

**定价：**

## 自动化架构

- **交给 Orkas / Claude Code**：网站审计、拿行业问题测 AI 回答、竞品对比、排版成 PDF、起草交付邮件和开发信。
- **交给 VPS 定时任务**：接收付款 webhook，生成任务队列，每月跑复查，把结果对比后发邮件。这部分用 Claude Code 或脚本来做，**不用 Orkas**，因为 Orkas 的定时任务要电脑开着、程序在运行，错过的任务只补跑最近一次，而且只在 12 小时内补跑。
- **仍要人做**：每份报告审 20 分钟，挡掉明显的胡话；回复客户的问题；每周写一篇行业对比文章。
- **稳定后每周**：大约 3 小时（按每周 5–8 份报告算）。

## 未来预测

- **6 个月**：Orkas 还会快速迭代。它现在有 6.8k 星、826 次提交，issue 里已经有人反馈 Windows 多任务时卡顿、在资料库之间移动文件可能丢编辑。推断它会继续加连接器和市场里的专员，但很难变成能托管运行的服务。同类的 Eigent（Apache-2.0）在 AlternativeTo 上显示有 15,654 星，桌面多代理会越来越同质化。
- **12 个月**：GEO 体检本身会越来越便宜（推断：自动扫描档已经低到 99 美元，工具化之后还会往下走）。卖单份报告的利润会被压缩，护城河只剩"按行业积累的问题库和对比数据"。不确定的地方是 AI 搜索会不会给出官方的可见度工具（像 Google Search Console 那样）；如果出了，这个生意基本就没了。
- **24 个月**：判断不了 Orkas 还在不在：它的定价页本身就前后矛盾（README 写付费"从 11.99 美元/月起"，定价页写 Lite 5.99 美元，首页又说 Lite 在排队），商业化还没定型。所以不要把流程绑死在它身上。

## 风险与对策

| 风险 | 对策 |
|---|---|
| **平台政策**：拿脚本批量去问 ChatGPT、Perplexity，可能违反它们的使用条款，被限流或封号 | 用官方 API（OpenAI、Perplexity 都有），不要模拟网页登录；控制频率 |
| **账号权限**：Gmail、Shopify 连接器能发信、改商品、删东西；语音输入会把音频传到 Orkas 的服务器 | 只授权专用的小号邮箱；不连客户的店铺；关掉语音输入；保持发送前确认 |
| **冷邮件合规**：给陌生外贸站批量发开发信，可能触发 Gmail 的垃圾邮件判定和各地的反垃圾邮件法规 | 用单独的发信域名，每天少于 30 封，带上退订方式 |
| **报告质量**：AI 审计会编出不存在的问题（第三方评测也提到 README 写的和代码实际做的不一致） | 每条结论都附截图或原始回答；人工审核这一步不能省 |
| **Orkas 停更或改成收费** | 第 2 周就把提示词和流程迁到 Claude Code，Orkas 只当原型工具 |
| **需求没被证明** | 前 30 份免费报告的回复率低于 5% 就停，不再投入 |
